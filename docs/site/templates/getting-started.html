Public product boundary

The harness builds the skills.
You only use the skills.

The internal engineering harness, research archive, fixtures, and release checks are development infrastructure. Published skills are designed to work independently and do not depend on that harness.

Preview locally

See the same site before it ships.

From the repository root, run the standard-library preview command. It rebuilds the publication artifact and starts a local server.

python docs/site/scripts/serve_site.py

Then open http://127.0.0.1:8000/. The existing docs/ directory is intentionally not used by this site.
