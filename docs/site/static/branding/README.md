# Website branding

The build copies the selected logo assets from the repository `assets/`
directory into the generated site. The source of truth is:

- `assets/intel-ai-skills-logo.svg`
- `assets/intel-ai-skills-logo-light.svg`
- `assets/intel-ai-skills-logo-dark.svg`
- `assets/intel-ai-skills-mark.svg`

The public site uses the Open Monogram identity with deep wine, cyan, navy, and
dark-surface colors. Do not create a second logo variant in `docs/site/`.
